I'm ManZ. I translate Super Famicom games into French and write the tools I do it with: [a816](https://github.com/manz/a816) the assembler, [katsuji](https://github.com/manz/katsuji) for the variable-width fonts, [kintsuki](https://github.com/manz/kintsuki) the emulator I trace them in. I also took an iPod classic's RetailOS apart and rebuilt it as Chikuma.

- [lab.ringum.net](https://lab.ringum.net): the translations and the tools, in French and English
- [chikuma.ringum.net](https://chikuma.ringum.net): open firmware for the iPod classic
- [man-you.ringum.net](https://man-you.ringum.net): maps, routing and backend from the day job
